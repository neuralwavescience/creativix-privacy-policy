Mobile Advertising Identifiers and Install Attribution

The Application uses Tenjin (operated by Tenjin, Inc., https://www.tenjin.com), a Mobile Measurement Partner (MMP), to understand which advertising campaigns or referral sources brought users to install the Application. This is called “install attribution” and is the only purpose for which the Application uses your mobile advertising identifier.


What is collected and shared with Tenjin:

  • Apple IDFA (Identifier for Advertisers) on iOS, only if you grant permission via the system “App Tracking Transparency” prompt
  • Google Advertising ID (GAID) on Android, unless you have enabled “Limit Ad Tracking” / “Opt out of Ads Personalization” in your device settings
  • Device-level information: device model, operating system version, language, country, install timestamp
  • Anonymous in-app events that help us understand which marketing channels deliver users who actually engage with the Application (for example: signup_complete, first_chat, paywall_view)

What is not collected for advertising purposes:

  • Your real name, email address, or phone number
  • The contents of your chats or files
  • Any payment card information

How to control this:

  • iOS: when the Application first launches you will see Apple's “App Tracking Transparency” prompt. Tapping “Ask App Not to Track” disables IDFA-based attribution. You can change this anytime in Settings → Privacy & Security → Tracking.
  • Android: open the Google Settings app → Ads → enable “Opt out of Ads Personalization” (or reset your Advertising ID). On Android 13+ the Application uses the standard AD_ID permission, which the system can also revoke.
  • In-app: users in regions covered by GDPR (EU/EEA, UK, Switzerland) or CCPA (California) see a Consent dialog the first time the Application launches and can revoke or re-affirm their choice anytime via Settings → Consent. Users outside these regions are not shown the dialog because their applicable laws do not require it; they may still control attribution via the OS-level settings above.

Tenjin's own privacy practices, retention periods, and contact information for data deletion requests are documented at https://www.tenjin.com/privacy-policy. Data deletion requests specific to Tenjin can be sent to privacy@tenjin.com.
